Generics in Java allow us to write classes, interfaces, and methods
 that work with different data types using type parameters. 
 They provide **type safety** at compile time, 
 reduce unnecessary type casting, and help create reusable code. 
For example, `ArrayList<String>` ensures that only String values can be stored in the list.
{
 public static void main(String[] args) {
        Box<Integer> a = new Box<> (10);
        Box<String> b = new Box<> ("Hello");
        System.out.println(a.getVal());
        System.out.println(b.getVal()+5);
    }
}
class Box<T> {
    private T val;
    Box(T val) {
        this.val=val;
    }
}
