A String in Java is a sequence of characters used to store text. 
It is a predefined class available in the java.lang package. 
Strings are immutable, meaning their values cannot be changed once created.
String literals are stored in the String Constant Pool to optimize memory usage.

string literals-> special place in heap called string pool in which string is stored 
and can be reused.
